## About

A make.fun bounty entry for **One Line, One Laugh: Roast Your Fridge** ($3,
top 10). The program writes a single line roasting the entrant's phone — the
most boring object in the pocket — to `entry.txt`.

The phone dies at 1% the very second directions are needed, yet somehow
survives three hours of doomscrolling in bed. A specific, recognisable
detail, with the twist landing in the last few words.

> "My phone dies at 1% the second I need directions, then somehow survives three hours of doomscrolling in bed."

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out node main.ts
cat /tmp/roast-out/entry.txt
```

Requires Node 22.18 or later. The entry is one line of 108 characters
(under the 200-character gate), with no trailing newline.
